## 1. 项目概述

### 1.1 项目背景

企业内部经常需要针对业务数据库做临时性、多样化的数据查询与统计。传统做法是为每个报表需求单独开发页面，周期长、维护成本高。本项目目标是构建一个**基于配置的在线报表系统**：由管理员在 Web 界面上配置数据源、SQL、查询条件与展示列，即可快速生成一个可查询、可导出的报表页面，无需改代码。

### 1.2 项目目标

- 报表"配置即上线"：新增一张报表不需要重新编译、发版
- 支持接入多种类型、多个实例的数据库（**必须支持 Oracle**）
- 提供表/字段元数据浏览能力，辅助编写 SQL
- 查询条件（输入框、下拉、日期范围等）完全由配置驱动
- 支持百万级结果集导出（流式 + 异步任务）
- 技术栈统一为 Go，单机单服务部署，预留 Docker 化能力

### 1.3 非目标（本期不做）

- 复杂报表设计器（拖拽式、交叉表、图表可视化）—— 后续版本考虑
- 定时任务调度、报表订阅推送
- 细粒度的行列级数据权限（本期仅做菜单/报表级权限）
- 多租户
- 分布式/集群部署（单机单服务）

### 2.1 Oracle 支持专项说明（v1.1 修正：双驱动路线）

**结论先行**：Oracle 支持**不再依赖 CGO**。默认构建走纯 Go 驱动 `go-ora`，Windows / Linux / macOS 任意平台、任意架构均可交叉编译；`godror`（CGO + Instant Client）保留为可选路线，用于需要 TNS 描述符、RAC 等高级场景。

| 路线 | 触发条件 | 优点 | 约束 |
|------|---------|------|------|
| **go-ora（纯 Go，默认）** | 默认构建（`build-and-run.bat` / `build-all.ps1`，`CGO_ENABLED=0`） | 零外部依赖、可交叉编译、部署即用 | 不支持 TNS 描述符直连串；需填「主机 + 端口 + 服务名/SID」 |
| godror（CGO，可选） | `CGO_ENABLED=1` + `-tags oracle` + Instant Client SDK | 官方 ODPI-C，支持 TNS/RAC | 需 MinGW-w64（Windows）/ gcc（Linux）+ Instant Client 运行时 DLL |

其他要点（两条路线共用）：

- **版本自动探测与方言适配**：连接后读 `v$version`，`datasource.OracleMajorVersion()` 解析主版本
  - 主版本 ≥ 12 → `OFFSET n ROWS FETCH NEXT m ROWS ONLY`
  - 主版本 ≤ 11（含解析失败的回退分支）→ `ROWNUM` 三层嵌套分页
  - 探测结果随连接池缓存，报表配置无感知；**同一服务内可同时接入 11g 与 19c 两个实例**
- 元数据扫描：`all_tables` / `all_tab_columns` / `all_col_comments`，支持「模式.表名」跨 schema 查询
- 占位符：Oracle 原生 `:name` 命名参数与项目约定的 `:param` 天然一致，Rebind 直通；但 **go-ora 的位置绑定语义要求参数按 SQL 中首次出现顺序去重**（引擎 `orderedArgs` 已处理）
- 大小写：`QuoteIdentifier` 输出 `"NAME"`，结果集列名统一按大写匹配，中文列名用双引号包裹

## 3. 系统总体架构

```
┌──────────────────────────────────────────────────────────┐
│              前端 (Vue 3 + Element Plus + Vite)            │
│  登录 │ 报表中心 │ 报表配置 │ 报表查看 │ 公开页 │ 系统管理   │
└───────────────────────┬──────────────────────────────────┘
                        │ REST API (JSON + JWT / 公开令牌)
┌───────────────────────▼──────────────────────────────────┐
│              Go 后端服务（单机单服务，:18080）              │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────────┐ │
│  │ 认证 RBAC │ │ 报表引擎  │ │ 元数据    │ │ 数据字典      │ │
│  │ JWT+权限点│ │ 参数绑定  │ │ 表/字段   │ │ 聚合/分离/SQL │ │
│  └──────────┘ └────┬─────┘ └────┬─────┘ └──────────────┘ │
│  ┌──────────┐ ┌────▼───────────▼──────────────────────┐  │
│  │ 导出服务  │ │  datasource.Manager（连接池注册表）      │  │
│  │ 流式/异步 │ │  Oracle(cgo/purego) MySQL PG MSSQL SQLite│  │
│  └────┬─────┘ └────────────────────────────────────────┘  │
│       │        ┌────────────────────────┐                 │
│  ┌────▼─────┐  │ 异步 Worker×N + 清理器   │                 │
│  └──────────┘  └────────────────────────┘                 │
└──────────────────────────┬───────────────────────────────┘
                           ▼
        导出文件目录(data/exports)   系统库(data/report_sys.db)
                                    业务数据源（Oracle/MySQL/PG/MSSQL/SQLite）
```

核心分层（与代码目录一一对应）：

1. **api 层**（`internal/api`）：路由、Handler、JWT 中间件、权限点校验（`RequirePerm`）、公开访问限流
2. **service 层**（`internal/service`）：auth / rbac / datasource / meta / report / query_engine / export / dict / column_config / audit
3. **datasource 层**（`internal/datasource`）：`Driver` 接口 + 注册表 `Manager`，五类实现
4. **model 层**（`internal/model`）：GORM 模型，AutoMigrate 建表
5. **webui 层**（`internal/webui`）：`go:embed` 嵌入前端产物、SPA 回落、未构建提示页

## 4. 功能需求详述（含实现状态）

> 标注：✅ 已实现　⚠️ 已实现但与初版设计有差异　⛔ 本期未实现（保留为后续优化）

### 4.1 数据源管理

**FR-01 数据源 CRUD** ✅

- 字段：名称、类型（mysql/postgresql/oracle/sqlserver/sqlite）、主机、端口、服务名/SID、库名、用户名、密码（AES 加密存储，接口返回脱敏）、连接参数（池大小/生命周期）
- ⚠️ Oracle 连接描述符直连（TNS 串）：纯 Go 驱动不支持；需 TNS/RAC 时用 `-tags oracle` 的 godror 版本

**FR-02 连接测试** ✅ —— 返回耗时与数据库版本（Oracle 显示 `v$version`，用于分页方言判定）

**FR-03 多实例支持** ✅ —— 任意数量数据源，报表配置时选择

**FR-04 连接池管理** ✅ —— 每数据源独立池（默认 MaxOpen 20 / MaxIdle 5 / MaxLife 3600s，可按数据源覆盖），配置变更即失效重建

### 4.2 元数据扫描

**FR-05 表清单扫描** ✅ —— 表/视图清单（名称、注释、类型），关键字搜索

**FR-06 字段扫描** ✅ —— 字段名、类型、可空、默认值、主键、注释；可一键复制字段名

**FR-07 元数据缓存** ✅ —— 进程内 TTL 缓存（`meta.cache_ttl_sec`，默认 300s）+ 单飞并发合并；关键字在缓存的全量清单上**内存过滤**（远程搜索不再逐字扫库）；`refresh=1` 强制重扫；数据源变更/删除/连接测试成功后自动失效；表数量受 `meta.table_limit` 限制并回传真实总数；**索引清单浏览已实现**（MySQL/PG/SQLServer/SQLite/Oracle）

### 4.3 报表配置

**FR-08 基于 SQL 创建报表** ✅

- 报表名称、分组、数据源、SQL 编辑器（自研高亮层 + textarea 双图层，行号、语法着色、字段/关键字补全、`Ctrl+S` 保存）
- SQL 使用命名参数占位符 `:param`，引擎统一绑定参数

**FR-09 查询条件配置（核心）** ✅ 并在实现中扩展

| 配置项 | 说明 | 实现补充 |
|--------|------|---------|
| 参数名 | 与 SQL 中 `:param` 对应 | **必须是合法标识符**（英文/下划线），与中文显示名解耦 |
| 显示名 | 页面中文标签 | 可与结果集中文列名一致或不同 |
| 列名(结果集) | — | **v1.0 新增**：自动装配模式下用于 `WHERE "中文列名" = :cond1`；留空回退参数名 |
| 控件类型 | 文本 / 数字 / 下拉单选 / 下拉多选 / 日期 / 日期时间 / 日期范围 | 文本与数字支持多行（一行一个值） |
| 匹配方式 | 等于 / 模糊 / IN / 范围 | 模糊不支持多值（保存/查询时明确报错并引导改「等于」） |
| 默认值 | 固定值 / 字典选项 / 动态宏（今天、近 7 天…） | 多选支持多值（数组 ↔ 逗号串） |
| 是否必填 | 必填未填阻止查询 | — |
| 选项来源 | 固定键值对 / **数据字典** / 自定义 SQL | 自定义 SQL 可引用其他条件 `:param` 实现级联 |
| 排序 | — | 表格拖拽排序，保存写 sortNo |

**FR-10 展示列配置** ✅ 并在实现中扩展

- 结果集列自动初始化；显示名、列宽、隐藏、排序、对齐、格式化（日期/千分位/小数）
- **v1.0 新增**：列绑定数据字典做值→标签翻译，列表/导出可分别选择显示「值 / 标签 / 两者」
- 用户级列配置（宽/序/显隐/冻结）单独存 `rpt_column_config`，**按用户隔离**，公开访问共用一套（UserID=0）

**FR-11 基于数据库表快速建报表** ✅ —— 报表中心「从表建报表」三步向导：选表 → 勾字段（别名/显示名/排序）→ 预览 SQL 并创建草稿；SQL 由后端 `POST /api/report-wizard/generate` 统一生成（标识符按需引号、跨模式表名校验、默认按主键 `ORDER BY` 保证分页稳定、自动生成条件草稿），**只生成不落库**，写入仍走 `POST /api/reports`；配置页内嵌「选表」流程保留并复用同一生成器。**支持大宽表**：制造实绩表单表常有几百上千列，字段数上限设 2000（高于 Oracle 1000 / PG 1664 / SQLite 2000 的单表列数），不再要求「分批建报表」；字段表格按 100 行/页分页渲染，生成的 SQL 超过 60KB（MySQL `TEXT` 上限）时给出「减少字段或缩短别名」的明确提示

**FR-12 报表预览与发布** ✅ —— 预览试跑（最多 100 行）、草稿/已发布/已停用三状态

### 4.4 报表使用

**FR-13 查询列表页** ✅（深分页优化 ⛔）

- 条件区 + 结果表格 + 分页（20/50/100）；后端分页按方言分发
- 排序白名单校验（仅展示列且允许排序的列可排）
- **COUNT 治理**（v1.0）：`COUNT(*)` 独立超时（默认 5s），超时降级为「总数未知」并返回首页数据；结果缓存 30s，翻页复用
- ⛔ keyset 游标分页未实现：深分页仍为 OFFSET，靠 COUNT 缓存 + 行数上限兜底

**FR-14 导出（核心）** ✅

| 档位 | 判定 | 处理方式 |
|------|------|---------|
| 小量 | 预估/直接查询 ≤ `export.sync_row_limit`（默认 1 万行） | 同步流式导出，直接写 HTTP 响应 |
| 大量 | 超阈值 | **异步任务**：入队 → Worker 执行 → 导出中心查看进度/下载 |

实现要点：

1. 任务表 `exp_export_task`：状态（pending/running/done/failed）、done_rows 进度、文件路径、行数、创建人/IP、耗时
2. 格式：默认 xlsx，可切 CSV；xlsx 单 Sheet 达 `xlsx_sheet_max_row`（默认 100 万）自动拆 Sheet2…
3. 流式落盘：excelize StreamWriter / bufio，不在内存攒全量
4. 文件管理：`data/exports`，按 `export.retention_days`（默认 7 天）定时清理；下载校验归属（公开报表走令牌校验）
5. ⚠️ 分片查询（按主键切片）与匿名一次性签名 URL 未实现（公开报表下载依赖 `X-Report-Token`）

**FR-15 慢查询治理** ✅（索引提示 ⛔）

| 手段 | 实现 |
|------|------|
| 查询超时 | 报表级 `queryTimeout`（默认 30s），`context.WithTimeout` + `Rows.Close()` |
| 行数上限 | 报表级 `rowLimit`（默认 10 万）强制 LIMIT |
| 异步隔离 | 慢导出走后台 Worker，不阻塞页面 |
| 只读保障 | 词法校验拒绝非 SELECT、多语句；建议数据源用只读账号 |
| 慢查询日志 | 超 `log.slow_query_ms`（默认 5s）记录 SQL 摘要与耗时 |
| 错误诊断 | `hintORA`（ORA-01036/01008/01722 等绑定/标识符错误给出中文排查提示）、`requeryErr`（附绑定参数与 SQL 摘要）、缺失表自动诊断 |

### 4.5 系统管理

**FR-16 用户与认证** ✅

- 独立用户名密码登录，JWT 签发（access 2h + refresh 7d），bcrypt 存储
- 权限模型：用户 → 角色（多选，权限取并集）→ 菜单/按钮权限点
- 内置角色：admin（隐式 `*` 全量权限，builtin 不可删）、user（仅已授权且已发布的报表）
- 菜单与权限点在「菜单管理」维护（M 目录 / C 页面 / F 按钮），角色在「角色管理」勾选；报表可见性也在角色管理页
- 接口 `RequirePerm("x:y:z")` 鉴权；前端 `can('x:y:z')` 控制按钮；权限变更即时生效（每次请求按库解析角色）
- 登录失败锁定：5 次锁 10 分钟（可配）；内置 admin 角色不可删除

**FR-17 报表公开访问** ✅

- 报表开启「公开访问」→ 生成 `public_id`(12 位) + 明文 token 返回一次，库存 SHA-256
- 链接形如 `/r/{public_id}?token={token}`；匿名请求头带 `X-Report-Token`
- 安全约束：仅暴露 info/query/options/export/column-config；IP 限流 30 次/分；导出默认关闭（`pubAllowExport`）；审计记为 anonymous + IP

**FR-18 报表分组与权限** ✅ —— 分组筛选 + 角色授权（`rpt_role_report`）

**FR-19 操作日志** ✅ —— 登录、查询、导出、配置变更、字典变更、权限变更均入库（`sys_audit_log`，含 SQL 摘要、耗时、IP、UA、TraceID、目标名称快照、失败原因）；写入为**有界队列 + 单 worker 批量落库**（队列满丢日志并计数，健康检查暴露 `auditDropped`）；`log.audit_retention_days` **自动清理已生效**（启动先清一次，之后每 6 小时，分批删除）；新增操作日志页面（筛选/详情/CSV 导出/按日期清理）

### 4.6 数据字典（v1.0 新增需求）

**FR-20 字典管理** ✅

- 三种来源：**分离式**（类型表 + 数据表，外键 → 类型编码）、**聚合式**（同表含类型列与键值/标签列）、**SQL 式**（自定义查询，按结果列映射）
- 字典 = 类型 + 键值 + 标签；下拉选项与展示列翻译复用同一份配置
- 表名支持跨模式 `模式名.表名`（如 `FGPESE0.SYS_DICT_TYPE`），全驱动适配（MySQL/PG/MSSQL/Oracle）
- 支持过滤条件、类型名称列、启停

**Driver 接口（实际签名）：**

```go
type Driver interface {
    BuildDSN(cfg ConnConfig) (string, error)
    Open(dsn string, cfg ConnConfig) (*sql.DB, error)
    ServerVersion(ctx context.Context, db *sql.DB) (string, error)
    ListTables(ctx context.Context, db *sql.DB, keyword string) ([]TableMeta, error)
    ListColumns(ctx context.Context, db *sql.DB, table string) ([]ColumnMeta, error)
    QuoteIdentifier(name string) string
    Rebind(query string) string                 // :name → 各库占位符（Oracle 直通）
    Paginate(query string, offset, limit int) string
}
```

Oracle 两个实现各自提供 `PaginateFor(version, ...)`，由 `oracle_common.OraclePaginate` 按版本分发。

## 9. 已决策项与遗留风险

### 已决策（v0.4 冻结 + v1.1 修正）

| # | 事项 | 决策 |
|---|------|------|
| 1 | Oracle 支持 | **必须支持**；**默认 go-ora 纯 Go（无 CGO、可交叉编译）**，godror 作为可选增强路线；12c 起步 + 11g 分页自动降级 |
| 2 | 认证 | 独立用户体系；报表可配置公开访问（public_id + token） |
| 3 | 百万级导出 | 同步流式 + 异步任务双模式；慢查询治理见 FR-15 |
| 4 | 部署 | 单机单服务（前端嵌入二进制）；Windows/Linux/macOS 三平台产物；预留 Docker |
| 5 | 导出格式 | 默认 Excel(xlsx)，支持 CSV；超单 Sheet 上限自动拆 Sheet |
| 6 | 系统库 | **SQLite（纯 Go 嵌入，单文件，WAL）**；MySQL 保留为可选 |
| 7 | 查询条件装配 | **两种模式并存**：SQL 中已写 `:param` 走内联绑定；未写则由引擎按配置自动拼 WHERE（`autoWrapSQL`），两种可混用 |
| 8 | 参数命名字符集 | 参数名必须是合法标识符，中文写显示名/列名，二者解耦 |

### 遗留风险

| # | 风险 | 说明与缓解 |
|---|------|-----------|
| 1 | 纯 Go Oracle 驱动能力边界 | 不支持 TNS 描述符/RAC 直连；需此类场景改用 `-tags oracle` 的 Windows 包，或填主机+端口+服务名 |
| 2 | 异步导出磁盘容量 | 百万行 xlsx 可达 1~2GB；默认 7 天清理，需监控 `data/exports` 容量 |
| 3 | 公开报表安全性 | 链接即凭证（token 明文仅在开启时返回一次）；默认禁导出 + 30 次/分/IP 限流；建议对外走 HTTPS |
| 4 | 审计日志增长 | 自动清理未实现，长期运行需手工/外部定时清理 `sys_audit_log` |
| 5 | 深分页性能 | 未做 keyset 游标；超大 OFFSET 依赖 COUNT 缓存与行数上限兜底 |
